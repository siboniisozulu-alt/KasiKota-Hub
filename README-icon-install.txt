Kota Connect icon files

Upload these five files into the ROOT of the KasiKota-Hub GitHub repository, beside index.html:
- manifest.json
- icon-192.png
- icon-512.png
- favicon-32.png
- apple-touch-icon.png

Your index.html already links to:
<link rel="manifest" href="./manifest.json">
<link rel="icon" type="image/png" sizes="32x32" href="./favicon-32.png">
<link rel="apple-touch-icon" sizes="180x180" href="./apple-touch-icon.png">

After uploading and committing the files, open the live website and check that these icon URLs load:
https://siboniisozulu-alt.github.io/KasiKota-Hub/icon-192.png
https://siboniisozulu-alt.github.io/KasiKota-Hub/icon-512.png
https://siboniisozulu-alt.github.io/KasiKota-Hub/manifest.json

Then install/update Kota Connect from Chrome. An already-installed app may need to be removed and installed again to refresh its icon.
